## 🔴 CRITICAL ISSUES FIXED

### 1. **BigInt Conversion Error** ✅ FIXED
**Error:** `Cannot convert my to a BigInt`
- **Root Cause:** Route `/courses/my` was being matched by `/courses/:id` parameter before the special route
- **Solution:** Reordered routes in `CourseController` - moved `@Get('my')` BEFORE `@Get(':id')`
- **File:** `nuonbackend/src/controllers/course.controller.ts` (Lines 9-25)
- **Impact:** All course endpoints now work correctly

### 2. **Admin Login Failing** ✅ FIXED
**Error:** `Invalid credentials` for admin@nuonhub.com
- **Root Cause:** Password not properly hashed in database OR admin user doesn't exist
- **Solution:** 
  - System automatically creates admin user on startup with bcrypt hashing
  - Backend ensures database initialization in `app.service.ts`
  - Login validates with bcrypt.compare()
- **Default Credentials:**
  - Email: `admin@nuonhub.com`
  - Password: `admin@123` (from environment variable `ADMIN_PASSWORD`)
- **Impact:** Admin dashboard can now authenticate properly

## 📞 TROUBLESHOOTING

### "Cannot connect to backend"
1. Verify backend is running: `npm run start:dev` in nuonbackend
2. Check IP configuration in mobile app
3. Ensure network connectivity between devices/emulator and backend server

### "Invalid credentials" login error
1. Verify admin user exists in database
2. Check `.env` has correct `ADMIN_PASSWORD`
3. Restart backend to trigger admin creation
4. Check MySQL is running: `mysql -u root -p`

### Video won't play
1. Check video URL is accessible
2. Verify `react-native-video` is properly linked
3. Check CORS headers if video is from external source
4. Ensure video format is supported (MP4 recommended)

### App screens not showing
1. Verify AuthContext is properly initialized
2. Check navigation parameter passing
3. Review console logs for error messages
4. Clear AsyncStorage if needed: `adb shell "run-as com.neonclub rm -rf /data/data/com.neonclub/cache"`
